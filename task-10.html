Задание 10. IP-адрес и маска подсети

В 2027 году это задание стоит под номером 10 (раньше было 13). Звучит страшно, а решается за минуту: вручную — одним делением, на Python — пятью строками.

Где это в жизни. У каждого устройства в сети — телефона, ноутбука, роутера — есть IP-адрес. Маска показывает, какая часть адреса — «номер сети» (как номер дома), а какая — «номер устройства» (как номер квартиры).

Как задание выглядит на ЕГЭ

Сеть задана IP-адресом одного из входящих в неё узлов 189.163.226.71 и сетевой маской 255.255.255.240. Найдите IP-адрес сети. В ответе укажите сумму числовых значений октетов найденного IP-адреса. Например, если бы найденный адрес был 100.20.3.4, то в ответе следовало бы записать 127. (ЕГЭ 2026, пересказ)

Вместо адреса сети могут спросить широковещательный адрес или наибольший адрес, который можно присвоить компьютеру. Ответ всегда — сумма четырёх чисел адреса. В 2027 году в проекте демоверсии именно такой формат.

Что нужно знать

  • IP-адрес — четыре числа от 0 до 255 через точку: 189.163.226.71. Каждое число называют октетом (в двоичной записи это 8 цифр).
  • Маска — тоже четыре числа. В двоичной записи у неё сначала идут одни единицы, потом одни нули. Поэтому в маске бывают только такие числа:

  • Адрес сети — первый адрес сети. У компьютера его быть не может.
  • Широковещательный адрес — последний адрес сети («всем сразу»). У компьютера его тоже быть не может.
  • Адреса компьютеров — всё, что между ними: от «адрес сети + 1» до «широковещательный − 1».

Способ 1. Вручную: метод «размера блока»

Иди по четырём числам маски слева направо:
  1. Где в маске 255 — число адреса переписываем как есть.
  2. Где в маске 0 — в адресе сети пишем 0, в широковещательном 255.
  3. Где в маске другое число (оно одно, «пограничное») — считаем блок = 256 − число маски. Число адреса делим на блок нацело и умножаем обратно — это число адреса сети. Прибавляем блок − 1 — это число широковещательного.

Почему это работает: маска делит числа от 0 до 255 на одинаковые блоки. Адрес сети — начало блока, в который попал наш адрес; широковещательный — конец этого блока.

Уровень 1. Двоичная запись и маска

Чтобы понимать, что происходит, нужно уметь записывать числа до 255 в двоичной системе. Разложи число на сумму из 128, 64, 32, 16, 8, 4, 2, 1: где слагаемое есть — пиши 1, нет — 0.

Разбор

Запишем 172 в двоичной системе.

  1. 172 ≥ 128 → пишем 1, остаётся 44.
  2. 44 < 64 → 0. 44 ≥ 32 → 1, остаётся 12.
  3. 12 < 16 → 0. 12 ≥ 8 → 1, остаётся 4.
  4. 4 ≥ 4 → 1, остаётся 0. Дальше 2 и 1 → 0, 0.
  5. Ответ: 10101100. Проверка на Python: print(bin(172)) → 0b10101100 (приставка 0b значит «двоичное»).

Уровень 2. Адрес сети

Разбор

Узел 64.237.228.143, маска 255.255.248.0. Найдите адрес сети, в ответе — сумма его чисел.

  1. Первые два числа маски — 255: переписываем 64 и 237.
  2. Последнее число маски — 0: в адресе сети там 0.
  3. Пограничное число маски — 248 (третье). Блок = 256 − 248 = 8. Третье число адреса: 228 // 8 = 28, 28 × 8 = 224.
  4. Адрес сети: 64.237.224.0. Сумма: 64 + 237 + 224 + 0 = 525.
  5. Проверка в двоичной системе (для понимания): 228 = 11100100, маска 248 = 11111000. Где в маске нули — в адресе сети нули: 11100000 = 224. Совпало.

Уровень 3. Широковещательный адрес и адреса компьютеров

Разбор

Узел 185.249.55.138, маска 255.255.192.0. Найдите широковещательный адрес.

Уровень 4. Сколько адресов в сети

Встречалось на ЕГЭ 2024–2026 годов. Количество адресов = 2число нулей в маске. Адресов для компьютеров на 2 меньше (без адреса сети и широковещательного).

Разбор

Маска 255.255.240.0. Сколько адресов в сети?

  1. Единиц в маске: 8 + 8 + 4 (240 = 11110000) + 0 = 20.
  2. Нулей: 32 − 20 = 12.
  3. Адресов: 212 = 4096. Для компьютеров: 4094.
  4. На Python: net.num_addresses — сразу даёт 4096.

Если спрашивают «сколько адресов, у которых число единиц в двоичной записи кратно 5» — перебираем все адреса сети программой:

from ipaddress import ip_network

net = ip_network('172.16.168.0/255.255.248.0', strict=False)
count = 0
for adr in net:
    ones = bin(int(adr)).count('1')
    if ones % 5 == 0:
        count = count + 1
print(count)
  • 5for adr in net:

    Что делает: перебирает все адреса сети по очереди — от адреса сети до широковещательного.

  • 6 ones = bin(int(adr)).count('1')

    Что делает: int(adr) — адрес как одно большое число, bin(...) — его двоичная запись, .count('1') — сколько в ней единиц.

    Что менять: если спрашивают про нули — тоже можно, но осторожно: bin не пишет ведущие нули. Нулей в 32-битном адресе = 32 − единиц.

  • 7–8 if ones % 5 == 0: count = count + 1

    Что делает: если число единиц делится на 5, увеличивает счётчик.

    Что менять: условие из задачи: «не кратно 2» — ones % 2 != 0.

Для учителя

Изменение 2027 года: задание переехало с номера 13 на номер 10 и стало базового уровня. Формат ответа «сумма октетов» уже был на ЕГЭ 2026 года и остался в проекте демоверсии 2027.

Сколько времени: одно занятие. Сначала двоичная запись (уровень 1), потом метод блока на доске, потом Python.

Как объяснять: аналогия «дом и квартира» для сети и узла. Метод блока объясняйте на числовой прямой 0…255, разрезанной на отрезки по 8, 16, 64 — сразу видно, в какой отрезок попал адрес.

Где ошибаются: путают широковещательный и наибольший адрес компьютера; забывают strict=False; в методе блока берут число маски вместо 256 − число.

Про задачи: каждый ответ посчитан программой (модуль ipaddress) и перепроверен отдельным расчётом через двоичные операции. Часть задач — на адресах из реальных экзаменов прошлых лет (формулировки свои), часть — свои.
