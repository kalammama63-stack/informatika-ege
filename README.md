# Информатика с нуля до ЕГЭ

Курс подготовки к ЕГЭ (КЕГЭ) 2027 по информатике для начинающих: Python, задания ЕГЭ, задачи с автоматической проверкой.

Python работает прямо в браузере (Pyodide 0.26.4, файлы в папке `pyodide/`), устанавливать ничего не нужно.

- `index.html` — главная: карта побед и список недель
- `week-NN.html` — уроки по неделям
- `course.js` — запуск Python, проверка задач и ответов
- `py-worker.js` — Python в отдельном потоке (защита от бесконечных циклов)
