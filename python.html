Перед заданиями с программой

Python за 2 урока

Здесь только те команды, из которых состоят шаблоны для ЕГЭ. Не нужно становиться программистом — нужно понимать каждую строку шаблона и знать, где его поменять.

Зачем это нужно. Шаблон на ЕГЭ почти никогда не подходит как есть: в задаче другая функция, другие числа, другой файл. Если понимаешь, что делает каждая строка, поправить шаблон — дело одной минуты. Если не понимаешь — шаблон бесполезен.

Где писать программы

На этом сайте. Под примерами есть окошки с кнопкой «Запустить». Первый запуск займёт 10–20 секунд (загружается Python), потом всё работает быстро. Код в окошке можно менять — пробуй!

На компьютере. На экзамене будет настоящий Python, к нему тоже нужно привыкнуть. Самая простая программа для новичка — Thonny (thonny.org): пишешь код в верхнем окне, нажимаешь зелёную кнопку ▶, результат появляется внизу.

Урок 1. Печать, переменные, логика, условие

1. print — напечатать

  • 1print("Привет!")

    Что делает: печатает текст в кавычках.

    Почему так: без кавычек Python решит, что Привет — это имя переменной, и выдаст ошибку. Кавычки только прямые: " или ', «ёлочки» не работают.

  • 2print(2 + 3)

    Что делает: сначала считает 2 + 3, потом печатает 5.

  • 3print("Ответ:", 7 * 6)

    Что делает: печатает несколько вещей через пробел.

    Почему так: запятая в print разделяет, что печатать. Так удобно подписывать результат.

2. Переменная — коробка с надписью

  • 1a = 5

    Что делает: кладёт 5 в коробку с надписью a.

    Почему так: знак = в Python — это не «равно», а «положи». Справа — что положить, слева — куда.

  • 2b = a * 2

    Что делает: достаёт из a пятёрку, умножает на 2, кладёт 10 в b.

  • 3a = a + 1

    Что делает: берёт старое значение a (5), прибавляет 1, кладёт обратно. Теперь a = 6.

    Почему так: с точки зрения математики это бессмыслица, но для «положи» — нормально: сначала считается правая часть, потом результат кладётся в коробку.

  • 4print(a, b)

    Что делает: печатает 6 10. Значение b не изменилось: его посчитали раньше, когда a было 5.

Имена переменных — латинскими буквами, без пробелов, не начинаются с цифры.

17 конфет на 5 друзей: каждому 17 // 5 = 3, в остатке 17 % 5 = 2. Остаток — самый полезный знак на ЕГЭ: «число делится на 7» на Python пишется n % 7 == 0 (остаток от деления на 7 равен нулю).

4. Правда и ложь: сравнения и логика

Сравнение даёт True (правда) или False (ложь). Для Python True — это 1, а False — это 0. Это очень пригодится в задании 2, где таблицы истинности из нулей и единиц.

  • 6print(x and y, x or y, not x)

    Что делает: печатает 0 1 False. «1 и 0» — ложь, «1 или 0» — правда, «не 1» — ложь.

    Почему печатает то 0, то False: and и or возвращают одно из своих чисел, а not — всегда True или False. Для проверок это неважно: 0 и False для Python одно и то же.

Скобки ставь всегда. В Python not слабее, чем ==: запись not x == y значит «не (x равно y)». Чтобы не гадать, бери в скобки каждую часть: (not x) == y.

5. Условие if — «если»

  • 1n = int(input())

    Что делает: input() берёт то, что ввели (на сайте — окошко «Ввод»), int() превращает текст в число.

    Почему так: input() всегда даёт текст. «14» и 14 для Python разные вещи: с текстом считать нельзя.

  • 2if n % 7 == 0:

    Что делает: проверяет условие «остаток от деления на 7 равен 0».

    Почему так: в конце строки с if обязательно двоеточие — так Python понимает, что дальше идёт то, что делать.

  • 3 print("делится на 7")

    Что делает: выполняется, только если условие верно.

    Почему отступ: 4 пробела (клавиша Tab) показывают, что строка внутри if. Отступы в Python — не для красоты, они меняют смысл.

  • 4–5else:

    Что делает: «иначе» — выполняется, если условие неверно. Пишется ровно под if.

Задача П.1. Вводится число. Выведи да, если оно делится на 3, и нет — если не делится.
Подсказка
Как в примере выше, только остаток от деления на 3: n % 3 == 0.

Урок 2. Циклы, перебор, функции

6. for — повторить для каждого

  • 1for i in range(5):

    Что делает: повторяет строки с отступом для i = 0, 1, 2, 3, 4.

    Почему так: range(5) — это числа от 0 до 4: пять штук, начиная с нуля. Python почти всё считает с нуля. Числа от 1 до 100 — это range(1, 101): правая граница не входит.

  • 2 print(i, i * i)

    Что делает: печатает число и его квадрат. Выполняется 5 раз, потому что стоит с отступом внутри for.

  • 3for letter in 'xyz':

    Что делает: for умеет идти не только по числам, но и по буквам строки, по элементам списка — по чему угодно.

7. Список, кортеж, множество

  • 1row = (1, 0, 1, 1)

    Что делает: кладёт в переменную несколько чисел сразу. В круглых скобках — кортеж, в квадратных [1, 0, 1] — список. Для наших шаблонов разницы почти нет.

    Почему так: строка таблицы истинности — это как раз несколько чисел подряд.

  • 2print(row[0], row[3])

    Что делает: берёт элемент по номеру. Нумерация с нуля: row[0] — первый, row[3] — четвёртый.

  • 3print(len(row))

    Что делает: len — сколько элементов. Здесь 4.

  • 4print(set([1, 0, 1, 1]))

    Что делает: set — множество: убирает повторы. Останется {0, 1}.

  • 5print(len(set([(1, 0), (1, 0), (0, 1)])))

    Что делает: было 3 строки, без повторов осталось 2.

    Зачем это на ЕГЭ: так проверяют, что все строки таблицы разные: если после set строк стало меньше — были одинаковые.

8. Функция — своя команда

  • 1def F(x, y):

    Что делает: создаёт свою команду F, которая принимает два значения и называет их x и y.

    Почему так: формулу пишем один раз, а используем сколько угодно. В задании 2 сюда пишется логическая функция из условия.

  • 2 return x * 10 + y

    Что делает: return — «верни ответ»: то, что получится, станет результатом F(...).

  • 4print(F(2, 5))

    Что делает: вызывает функцию с x = 2, y = 5 и печатает 25.

9. Перебор всех вариантов: product и permutations

В Python есть готовые команды для перебора. Их нужно подключить строкой from itertools import ....

  • 1from itertools import product, permutations

    Что делает: подключает две готовые команды из набора itertools.

    Почему так: писать перебор самим долго и легко ошибиться. На экзамене эти команды доступны.

  • 3for a, b in product([0, 1], repeat=2):

    Что делает: перебирает все сочетания: a и b каждое бывает 0 или 1. Получится 00, 01, 10, 11.

    Почему так: [0, 1] — какие значения бывают, repeat=2 — сколько переменных. Для четырёх переменных — repeat=4 и 16 вариантов.

  • 6for p in permutations('xyz'):

    Что делает: перебирает все способы расставить буквы x, y, z по порядку: xyz, xzy, yxz… всего 6.

    Зачем это на ЕГЭ: в задании 2 нужно понять, какая буква в каком столбце, — перебираем все расстановки.

  • 7 print(p, ''.join(p))

    Что делает: p выглядит как ('y', 'x', 'z'), а ''.join(p) склеивает буквы в слово yxz — ровно в таком виде пишут ответ.

10. Где стоит буква: index

  • 2print(p.index('x'))

    Что делает: ищет, на каком месте стоит 'x'. Печатает 2 (счёт с нуля: y — 0, z — 1, x — 2).

  • 4print(row[p.index('x')])

    Что делает: «найди, в каком столбце x, и возьми из строки число оттуда». Печатает 1.

    Зачем это на ЕГЭ: это главная строка шаблона задания 2 — она переводит столбцы таблицы в значения x, y, z, w.

11. continue — «пропусти этот круг»

  • 3 continue

    Что делает: сразу переходит к следующему повтору цикла, остальные строки пропускаются. Здесь печатаются только чётные: 0, 2, 4.

    Зачем это на ЕГЭ: отбросить неподходящий вариант и не проверять его дальше.

Задача П.2. Перебери все сочетания x, y, z из нулей и единиц и напечатай (через пробел) только те, где x <= y и y <= z и z равно 1.

Внутри цикла: if x <= y and y <= z and z == 1: и под ним с отступом print(x, y, z).

Подсказка
После цикла (без отступа!) допиши print(count).
Вот и всё. Этих команд хватает для шаблонов большинства заданий ЕГЭ. Дальше на странице каждого задания шаблон разобран построчно — там будут встречаться только эти команды.
Для учителя

Как вести: два занятия. Урок 1 — разделы 1–5 и задача П.1. Урок 2 — разделы 6–11 и задачи П.2–П.3. Каждый пример ученик запускает сам и что-нибудь в нём меняет: «а что будет, если…».

Где ошибаются: = вместо ==; забытое двоеточие; отступы; счёт с единицы вместо нуля (row[1] — это второй элемент); range(1, 100) не включает 100.

Не надо подробно объяснять типы данных, классы и прочее. Цель — читать и править шаблоны.
