Для учителя: как устроены страницы

Каждая неделя — одна страница на 3 занятия. Порядок на странице: зачем это нужно → объяснение → примеры, которые можно запустить → разбор по шагам → задачи с проверкой → задание ЕГЭ недели → домашнее задание.

Задачи с кнопкой «Проверить» запускают программу ученика на нескольких скрытых примерах. Задачи с полем «Ответ» проверяют только число, как на экзамене.

Код и решённые задачи сохраняются в браузере ученика. Если он откроет сайт на другом устройстве, там будет чисто.

Python на сайте нужен для тренировки дома и с телефона. На уроках лучше работать в обычном Python на компьютере (IDLE или Thonny), чтобы к экзамену привыкнуть к настоящей среде.

Курс сверен с проектом демоверсии ФИПИ 2027. Окончательная демоверсия ожидается в ноябре 2026 года.
