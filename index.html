Для учителя: как устроены страницы

Страница задания: как оно выглядит на ЕГЭ → нужные слова → метод → уровни от простого к сложному (на каждом разбор по шагам и задачи) → «Как на ЕГЭ» → ловушки → блок «Для учителя».

Все задачи составлены для курса и проверены программой. У каждой есть подсказка и краткое решение. Решённые задачи сохраняются в браузере ученика.
