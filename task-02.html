Задание 2. Таблица истинности

Дана логическая функция и кусочек её таблицы. Нужно понять, какая буква в каком столбце. Вручную это головоломка, а с шаблоном на Python — пять минут работы, даже если логику ты пока не понимаешь.

Перед этим заданием пройди Python за 2 урока. Там объяснены все команды, из которых состоит шаблон: функция, перебор, index, join.

Как задание выглядит на ЕГЭ

Логическая функция F задаётся выражением (x → y) ∧ ¬(y ≡ z) ∧ ¬w.

Дан частично заполненный фрагмент таблицы истинности функции F, содержащий неповторяющиеся строки. Определите, какому столбцу таблицы соответствует каждая из переменных x, y, z, w.

????F
001
1001
0001

В ответе напишите буквы x, y, z, w в том порядке, в котором идут соответствующие им столбцы.

Что тут важно:

  • Над столбцами стоят знаки вопроса — какая там буква, нам и нужно узнать.
  • Некоторые клетки пустые — там может быть и 0, и 1.
  • Строки не повторяются — это подсказка, она отсекает часть вариантов.
  • В столбце F бывают все единицы или все нули (на ЕГЭ 2026 года чаще встречались нули).
  • Ответ — четыре буквы подряд, например yzxw.

Шаг 1. Переводим функцию на Python

Это единственная часть, где нужно думать. Каждый знак меняем по таблице:

На ЕГЭНазваниеНа PythonПочему так
¬xНЕ (отрицание)not xто же слово по-английски
x ∧ yИ (конъюнкция)x and yто же слово по-английски
x ∨ yИЛИ (дизъюнкция)x or yто же слово по-английски
x → yимпликация, «если x, то y»x <= yсм. ниже
x ≡ yэквивалентность, «x равно y»x == yправда, когда значения одинаковые

Почему импликация — это <=

Импликация «если x, то y» ложна только в одном случае: x = 1, а y = 0 (обещали — и не сделали). Сравним с x <= y («x не больше y»):

xyx → yx <= y
0010 <= 0 — правда (1)
0110 <= 1 — правда (1)
1001 <= 0 — ложь (0)
1111 <= 1 — правда (1)

Столбцы совпали во всех четырёх строках. Значит, x <= y и есть импликация. Проверь сам:

Два правила скобок.
  1. Сохраняй все скобки из условия. Если в условии ¬(y ≡ z), пиши not (y == z), а не not y == z.
  2. Отрицание рядом с == и <= бери в скобки. x ≡ ¬y — это x == (not y). Без скобок Python выдаст ошибку.

Пример: (x → y) ∧ ¬(y ≡ z) ∧ ¬w → (x <= y) and not (y == z) and not w.

Шаг 2. Шаблон: разбор каждой строки

Это программа для задачи из начала страницы. Она перебирает все варианты для пустых клеток и все расстановки букв по столбцам и печатает ту расстановку, которая подходит. Сначала прочитай объяснение каждой строки, потом нажми «Запустить» внизу.

from itertools import product, permutations

def F(x, y, z, w):
    return (x <= y) and not (y == z) and not w

answers = set()
for a, b, c, d in product([0, 1], repeat=4):
    table = [(0, a, b, 0, 1),
             (1, 0, c, 0, 1),
             (d, 0, 0, 0, 1)]
    if len(set(table)) < len(table):
        continue
    for p in permutations('xyzw'):
        ok = True
        for row in table:
            x = row[p.index('x')]
            y = row[p.index('y')]
            z = row[p.index('z')]
            w = row[p.index('w')]
            if F(x, y, z, w) != row[4]:
                ok = False
        if ok:
            answers.add(''.join(p))
print(answers)

Уровень 1. Разминка: считаем логику на Python

Сначала научимся просто переводить и вычислять. Для подсчёта строк пригодится короткий шаблон «печать таблицы»:

from itertools import product
print('x y z w')
for x, y, z, w in product([0, 1], repeat=4):
    F = ((x and not y) <= z) == (w or x)
    if F == 1:
        print(x, y, z, w)

Задача 1.1. Чему равно (x → y) ∧ ¬z при x = 1, y = 0, z = 0? Ответ: 0 или 1.
Решение
На Python: (x <= y) and not z. Подставь значения или запусти в окошке: x = 1; y = 0; z = 0; print(int((x <= y) and not z)). Ответ: 0.
Задача 1.2. Чему равно (x ∨ y) ≡ ¬z при x = 0, y = 0, z = 1? Ответ: 0 или 1.
Решение
На Python: (x or y) == (not z). Подставь значения или запусти в окошке: x = 0; y = 0; z = 1; print(int((x or y) == (not z))). Ответ: 1.
Задача 1.3. Чему равно ¬(x ∧ y) → (z ≡ w) при x = 1, y = 0, z = 1, w = 0? Ответ: 0 или 1.
Решение
На Python: (not (x and y)) <= (z == w). Подставь значения или запусти в окошке: x = 1; y = 0; z = 1; w = 0; print(int((not (x and y)) <= (z == w))). Ответ: 0.
Задача 1.4. В скольких строках полной таблицы истинности функции (x → y) ∧ (y ≡ ¬z) значение F равно 1?
Решение
В шаблоне печати поставь F = (x <= y) and (y == (not z)) и условие if F == 1, посчитай напечатанные строки. Ответ: 3.
Задача 1.5. В скольких строках полной таблицы истинности функции ((x ∧ ¬y) → z) ≡ (w ∨ x) значение F равно 1?
Решение
В шаблоне печати поставь F = ((x and not y) <= z) == (w or x) и условие if F == 1, посчитай напечатанные строки. Ответ: 10.

Ловушки

Для учителя

Сколько времени: два занятия. Первое: перевод на Python (таблица знаков, почему → это <=), уровень 1, построчный разбор шаблона. Второе: уровни 2–4 и «Как на ЕГЭ».

Как объяснять шаблон: не целиком, а по частям. Сначала функция F и проверка одной строки вручную. Потом цикл по расстановкам букв (без пустых клеток — это уровень 2). И только потом перебор пустых клеток.

Где ошибаются: в переводе функции (скобки, отрицание рядом с ==), в числе пустых клеток, забывают поменять значение F на 0.

Ручной способ (рассуждением по строкам, где F = 1 или F = 0) полезен сильным ученикам — он показан в разборе уровня 4. Но на экзамене шаблон надёжнее: меньше шансов ошибиться в логике.

Про задачи: все функции и таблицы составлены для курса. Перевод каждой функции на Python проверен по полной таблице истинности, у каждой задачи перебором проверено, что ответ единственный, а заполненный шаблон в «Решении» запущен и даёт этот ответ.
